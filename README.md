# 🤖 NPCBook — NPC OMNIVERSE

> **Everyone has a profile. Nobody has a purpose.**

NPCBook is a fast, responsive fictional-character explorer generated by Python and served as a static site.

## ✨ Upgraded

- 📱 Responsive mobile/tablet/desktop UI
- 📲 Installable PWA with manifest + service worker
- 🤖 Custom favicon and app identity
- 🔎 Instant search + `/` keyboard shortcut
- 🧭 NPC / World / Quest / Lore filters
- 🎲 Random discovery
- 🔍 Detail modal
- ↗ Native share with clipboard fallback
- 📸 Client-side PNG screenshot export
- 🌗 Theme toggle
- 🧱 Custom 404 page
- 🔎 SEO + Open Graph + canonical metadata
- 🗺️ Sitemap + robots.txt
- ♿ Reduced-motion support
- 🚫 No database, accounts, cookies, localStorage or sessionStorage
- ⚡ No external API required

## 🏗️ Build

```bash
python app.py
```

The generator creates:

```text
site/
├── index.html
├── 404.html
├── favicon.svg
├── manifest.webmanifest
├── sw.js
├── robots.txt
└── sitemap.xml
```

For local PWA testing:

```bash
python -m http.server 8000 --directory site
```

Then open `http://localhost:8000`.

## 🌐 Render

Use a **Static Site**:

- Build Command: `python app.py`
- Publish Directory: `site`

A `render.yaml` is included with the project configuration.

## 🧠 Content

Edit the NPC, world, quest and lore data directly in `app.py`, then rebuild. The browser provides search, filters, sharing and screenshot generation without a backend.

## 🧪 CI

GitHub Actions automatically:

1. Runs Python syntax validation.
2. Builds the static site.
3. Verifies the generated PWA/SEO assets exist.
4. Checks core SEO, PWA and accessibility hooks in the generated HTML.

## ♿ Accessibility & UX

The explorer includes a skip link, labeled search control, keyboard shortcuts, Escape-to-close dialogs, live result updates, reduced-motion support, responsive layouts, offline/online feedback and a reversible light/dark theme.

## 🔐 Privacy

NPCBook is intentionally stateless. No user account or persistent application database is required. UI state lives only in the current page.

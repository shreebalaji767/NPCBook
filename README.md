# 🤖 NPCBook — NPC OMNIVERSE

> **Everyone has a profile. Nobody has a purpose.**

NPCBook is a fast, responsive fictional-character explorer generated by Python and served as a static site.

## ✨ Upgraded

- 📱 Responsive mobile/tablet/desktop UI
- 📲 Installable PWA with manifest + service worker
- 🤖 Custom favicon and app identity
- 🔎 Instant search + `/` keyboard shortcut
- 🧭 NPC / World / Quest / Lore filters
- 🎲 Random discovery
- 🔍 Detail modal
- ↗ Native share with clipboard fallback
- 📸 Client-side PNG screenshot export
- 🌗 Theme toggle
- 🧱 Custom 404 page
- 🔎 SEO + Open Graph + canonical metadata
- 🗺️ Sitemap + robots.txt
- ♿ Reduced-motion support
- 💾 `localStorage` keeps a persistent history of generated universes so refreshes do not repeat them
- 🗃️ Local Library archives up to 12 generated universes for reload/restore
- ⭐ Save up to 100 favorite NPCs, quests, worlds and lore entries
- ⬇️ Export the current universe as portable JSON
- ⬆️ Import a previously exported universe back into NPCBook
- 🧹 One-click local-library reset
- 🚫 No database, accounts, cookies or sessionStorage
- ⚡ No external API required

## 🏗️ Build

```bash
python app.py
```

The generator creates:

```text
site/
├── index.html
├── 404.html
├── favicon.svg
├── manifest.webmanifest
├── sw.js
├── robots.txt
└── sitemap.xml
```

For local PWA testing:

```bash
python -m http.server 8000 --directory site
```

Then open `http://localhost:8000`.

## 🌐 Render

Use a **Static Site**:

- Build Command: `python app.py`
- Publish Directory: `site`

A `render.yaml` is included with the project configuration.

## 🌌 New Universe on Every Refresh

Every page refresh creates a new fictional universe in the browser. The current universe is also cached locally so it can be exported or restored.

- 🌍 A fresh universe/world name is generated on every refresh
- 🤖 NPCs, quests and lore are regenerated from randomized pools
- 🚫 Previously generated universe signatures are not reused
- 💾 The history ledger, current universe, saved items and small local archive are stored in `localStorage`
- 📦 Imported/exported universes are plain JSON and never leave the browser unless the user explicitly shares the file
- 🧹 Clearing site data resets the local history and allows old universes to appear again

The browser still provides search, filters, sharing and screenshot generation without a backend.

## ♿ Accessibility & UX

The explorer includes a skip link, labeled search control, keyboard shortcuts, Escape-to-close dialogs, live result updates, reduced-motion support, responsive layouts, offline/online feedback and a reversible light/dark theme.

## 🔐 Privacy

NPCBook does not use a user account or application database. Local browser storage is used for universe signatures, the current universe, up to 12 archived universes and up to 100 saved items. Nothing is uploaded by these features.
